# Analysis

- Software / dependencies: Python 3.12 with pandas, numpy, scipy, matplotlib, requests and openpyxl. R with HonestDiD, contdid and doParallel, used only for two sensitivity checks on the London event study (`83_honestdid.R`, `85_contdid.R`). LaTeX (pdflatex with pgfplots) for the report and the supervision summary.
- Input files and locations: Raw downloads are fetched by the scripts into a folder outside the repository, set by the `LONDON_VARIETY_RAW` and `LONDON_VARIETY_EXT_RAW` environment variables (by default `~/research-data/london-variety/raw` and `~/research-data/london-variety-extension/raw`). Each script skips a download when the raw file already exists. The cleaned inputs to every estimation are included in `london-variety/data/clean/` and `london-variety/extension/data/clean/`, so the estimates can be checked without downloading the raw data.
- Steps or commands, in order:
  1. `python london-variety/scripts/run_all.py` builds the London panel and runs the London event studies and triple differences (scripts `10` to `98`, in numbered order).
  2. `python london-variety/extension/run_all.py` assembles the England and Wales data (steps `b1` to `b6`, `s1`, `s3`, `s4`), runs the registered national designs (`s2` to `s5`), the analyses chosen after the registered results (`s8`), and then the venue-mix (`venue_mix/scripts/v1` to `v8`) and recovery (`recovery/scripts/r1` to `r6`) designs. A single step can be run with `--only <script>`.
  3. `python london-variety/scripts/99_report.py` writes the full report, `london-variety/outputs/report/report.tex`, from the estimation outputs, which is then compiled with pdflatex.
  4. The supervision summary, `london-variety/outputs/supervision/Paper7_Supo3.tex`, was first generated by `london-variety/scripts/99_supervision.py` and then edited by hand, so the `.tex` file is the final version.
- Output files: Listed in [outputs.md](outputs.md).

The pre-analysis plans are `london-variety/extension/PRE_ANALYSIS_PLAN.md`, `london-variety/extension/venue_mix/PRE_ANALYSIS_PLAN.md` and `london-variety/extension/recovery/PRE_ANALYSIS_PLAN.md`, each beside a `.sha256` file whose checksum can be compared with `sha256sum PRE_ANALYSIS_PLAN.md`.
